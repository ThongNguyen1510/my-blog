# My Blog

Dự án blog cá nhân được xây dựng với mục tiêu chia sẻ kiến thức và trải nghiệm.

## Thông tin dự án

Dự án này sử dụng React kết hợp với Vite để đảm bảo tốc độ phản hồi nhanh và hiệu năng tối ưu. Giao diện được thiết kế hiện đại, tối giản và hỗ trợ hiển thị tốt trên mọi thiết bị.

## Hướng dẫn phát triển (Local Development)

Để chạy dự án này trên máy tính của bạn, hãy đảm bảo bạn đã cài đặt [Node.js](https://nodejs.org/) (khuyên dùng phiên bản LTS).

Theo dõi các bước sau:

```sh
# Bước 1: Clone repository
git clone [https://github.com/ThongNguyen1510/my-blog.git](https://github.com/ThongNguyen1510/my-blog.git)

# Bước 2: Di chuyển vào thư mục dự án
cd my-blog

# Bước 3: Cài đặt các thư viện cần thiết
npm install

# Bước 4: Khởi chạy môi trường phát triển (Development Server)
npm run dev
